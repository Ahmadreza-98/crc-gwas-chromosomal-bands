`original_analysis_redacted.R` is a provenance copy of the working R script from the original research workflow.

It is **not** the recommended script to run. Use the repository-root `analysis.R` for the cleaned, path-independent workflow.

Before public release, one machine-specific line was redacted:

```r
setwd('<original local working directory>')
```

No analytical formula, threshold, statistical test, data-processing step or result-generating code was intentionally changed in this archived copy. The redaction only removes a personal local filesystem path.

The historical script retains exploratory code, repeated sections and package dependencies that reflect how the analysis developed over time. Those features are kept for provenance rather than polished execution.
