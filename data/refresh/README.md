# Refreshed data

Optional rerun scripts write current database-dependent results here.

`analysis.R` checks `data/refresh/` first. If a complete refreshed result is present, it is used for that stage. Otherwise the final published result under `data/archived/` is used.

Current online resources may differ from the versions used for the paper, so refreshed p-values and annotations are not expected to be identical in every case.

To return to the published analysis, remove the generated files from this folder.
